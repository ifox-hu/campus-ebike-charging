# 首页交互与联机配置

## 首页标题与排序

首页标题为“充电站点”，说明为“电动自行车插座充电”，采用上下排列。

“全部站点”按默认顺序显示，“空闲较多”按可用插座数降序排列。选中状态、排序说明和结果数随操作更新，搜索可与排序组合使用。

## 站点与订单

联网模式从后端读取站点、设备、插座、费率、订单和报修记录。用户启动充电后，管理端可查询同一订单；结束后两端显示同一账单和插座状态。

本地演示使用浏览器存储，联网模式通过 `/api` 读写业务数据。接口说明见 [后端联调](backend-integration.md)。

## 运行配置

| 服务 | 默认端口 |
| --- | --- |
| 用户端本地演示 | 5197 |
| 用户端联网模式 | 5198 |
| 管理端联网模式 | 5201 |
| 业务后端 | 8081 |

调整后端端口时，同步修改两端的 API 代理目标。更新后端时，先备份数据库并执行对应的增量迁移，再构建和重启服务。微信端构建完成后，在开发者工具中重新导入 `dist/build/mp-weixin/`。

## 检查项目

- 搜索、排序和场景筛选可组合使用。
- 使用不同初始顺序的站点检查排序，切回“全部站点”后恢复默认顺序。
- 检查320/390px布局、空结果、当前任务和返回后的筛选状态。
- 核对用户端启动、管理端查单、结束结算和报修反馈。
