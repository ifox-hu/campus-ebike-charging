## 首页问题原因与修复

“电单车站场／两轮插座充电”原本就是标题和说明，只有文字，没有点击事件；下划线和横向排布造成了标签页误解。现改为上下排列的“充电站点／电动自行车插座充电”。

下方“全部站点”恢复默认顺序，“空闲较多”按可用插座数降序排列。示例默认顺序本来已按72、54、48排列，因此点击后列表看起来相同。现保留真实排序，并明确显示选中状态、排序说明及结果数。浏览器测试使用不同初始顺序验证实际重排和恢复，同时覆盖搜索及320/390px布局。

## 源码、构建与服务的区别

Git合并只更新源码，不会自动替换已运行的后端JAR、修改MySQL或更新另一个目录的微信构建产物。原8081进程与既有数据库保留；可用的联网演示为H5 5198、管理端5201、隔离后端18081。正式数据库升级需执行V6/V7后再启动对应新后端，不能将尚未迁移的旧数据库直接接新实体。

本地H5原目录可用5196，worktree为5197。原目录小程序产物需在 `云创用户端` 执行 `npm run build:mp-weixin` 后，导入该目录 `dist/build/mp-weixin` 重新编译。微信AppID、合法域名和真机运行仍需单独验收。
