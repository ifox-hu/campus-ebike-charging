# 移动端页面设计

设计日期：2026-11-09。

## 界面参考

界面参考云创公开页面的站点地图、底部站点卡片和设备选择布局，采用青绿色按钮、白色信息卡和城市插画。图标及素材保留来源信息。

## 页面

- 找站：地图示意、列表、名称搜索和站点状态。
- 站点详情：地址、设备排、在线状态、空闲/总插座数。
- 插座选择：设备下的A/B插座及可用状态。
- 充电：方案选择、启动确认、当前任务、结束结算和模拟支付。
- 个人使用：订单详情、报修、个人中心。

页面使用uni-app共用源码，H5和微信小程序分别构建，状态通过共享store管理，本地记录使用uni存储。

## 初版业务规则

初版演示功率为300 W，电费0.60元/kWh、服务费0.20元/kWh。启动时保存费率快照，金额以分计数，历史订单保留原结果。

空闲插座可启动，占用、故障和离线插座显示不可用。重复启动、结束和支付返回原订单或结果。未知编号提供错误提示。

微信端调用 `uni.scanCode`，H5提供编号输入入口；扫码内容解析为已知插座编号或带socket参数的链接。

## 页面检查

检查地图与列表切换、搜索、站点和插座状态、启动、结束、支付、历史订单、报修及窄屏滚动，构建H5和微信小程序。
