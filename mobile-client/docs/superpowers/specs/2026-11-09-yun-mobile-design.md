用户要求：管理端另一任务继续一比一复刻慧知；本任务同步开发参考 YunCharge/云创智城小程序页面的 H5 和微信小程序。

## 方案与决定
2026-11-09 用户进一步明确：移动端优先使用云创小程序原始源码，按照原实现方式和页面效果一比一复刻后适配本项目。先前独立 uni-app Vue 3 工程仅是待采用的构建准备，尚未实现任何替代 UI。不得将自行重绘页面称为云创原版源码。

核验结果：公开 GitHub 组织仅检索到 YunCharging、YunParking、charging-cloud-web、canal1.1.4；YunCharging 只有 master 分支，268 个树项，没有 .vue/.wxml/pages.json/manifest.json/package.json；sharecharge-applet 是 Java 接口模块。官网指向的 Gitee yuncitys/YunCharging 已成功下载，提交 87288ea1498dbecce023520709c04ed4b439c014，只有 README 和图片。caoyingde/YunChargeCloud 返回 403。

用户补充授权：若该账号内没有小程序源码，则研读官方文档细节自行实现。因此继续独立实现，按可核对的官方页面布局比对，不声称复用了未取得的源码。页面内地图与充电数据仍清楚标为本地模拟。

## 界面依据
参考 `../UI方案参考/真实充电项目参考/yun-mobile-bike.jpg` 与 `yun-mobile-detail.jpg`；原始出处 https://www.yuncitys.com/yun_charging.html 。已保存参考图，但未取得对应小程序完整源码，不声称这是上游原版或每页一比一复刻。地图首页使用青绿色按钮、站点底部卡；站点详情使用城市插画、白色信息卡、设备在线状态、空闲/总插座数及底部扫码入口。

## 本轮范围
可体验页面：找站（地图示意与列表、搜索）、站点详情、插座选择、启动确认、充电中、结算/模拟支付、订单详情、我的、报修。
本轮是明确标记的前端本地演示：不用厂商接口、真实设备或真实支付。模拟状态和订单用 uni 存储保留，H5 与开发者工具各自存储，尚不跨端同步。普通用户身份为演示身份，不声称已完成后端鉴权。
计费为示例电费 0.60 元/kWh、服务费 0.20 元/kWh；模拟功率 300W；主动推进模拟时长，避免浏览器刷新和后台挂起误计费。启动时保存费率快照，金额以分计数。不能启动占用、故障、离线设备的插座；重复启动不产生两个有效订单；重复结束/支付不得重复计费。未知编号明确报错。历史订单保留结束状态。
扫码：微信调用 uni.scanCode，H5 用输入编号/测试编号入口。扫码内容只接受已知插座编号或带 socket 参数的链接，不访问扫描的任意网址。
地图两端均为清楚标注的布局示意，不采集定位、不显示虚构真实距离；真实地图与后端接入留在下一阶段。
并行边界：只写“云创用户端”目录；不修改“慧知界面复刻”、现有后端/前端/miniapp、原版预览区。未提交、推送或发布。
