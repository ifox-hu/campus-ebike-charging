# 移动端使用说明

用户端位于 `mobile-client/`，与 `frontend/` 管理端连接同一业务后端。支持本地 H5 演示和联网运行，也可构建微信小程序。

## 运行与构建

在 `mobile-client/` 目录执行：

```bash
npm ci
npm test
npm run dev:h5
```

本地演示默认端口5197。联网运行使用 `npm run dev:connected`，默认端口5198，通过 `/api` 访问后端。接口配置见 [后端联调](backend-integration.md)。

```bash
npm run build:h5:connected
npm run build:mp-weixin
```

微信构建输出到 `dist/build/mp-weixin/`。在 `src/manifest.json` 配置 AppID，并在开发者工具中导入该目录。

## 页面交互

- 首页提供场景筛选、站点搜索、排序和当前充电入口。
- 站点详情按排展示设备，每台设备提供 A/B 两个独立插座。
- 充电确认页显示方案和预计电费，提交期间禁用重复操作。
- 充电中页面显示时长、电量和功率；结束后查看账单并选择模拟支付方式。
- 订单列表支持筛选，查看详情后返回时保留筛选条件。
- 设备和插座入口可带入报修编号，用户查看处理状态与进度。
- 微信自定义导航栏按状态栏和胶囊位置留白，底部操作区适配安全区。
- 空列表、无效链接、网络失败和登录失效分别提供提示与返回入口。

## 页面检查

浏览器检查覆盖搜索、插座不可用、当前任务入口、结束结算、模拟支付、报修、筛选恢复和320/390px布局。微信端检查扫码成功与取消、导航栏位置、键盘遮挡、返回操作及充电流程。

共享测试命令见 [项目测试说明](../../docs/testing.md)。
