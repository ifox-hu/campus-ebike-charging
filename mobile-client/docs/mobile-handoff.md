## 本地验收方式

在当前 worktree 执行：

```powershell
npm ci
npm test
npm run build:h5
npm run build:mp-weixin
npm run dev:h5
```

本分支预览端口为 `http://127.0.0.1:5197/`，原移动端可继续使用 5196。

可选浏览器回归脚本使用已安装的 Microsoft Edge：先执行 `npm install --no-save --package-lock=false playwright`，启动 H5，再执行 `node qa/verify-mobile.cjs`。Playwright 只用于本机验收，没有加入业务运行依赖。脚本输出 `qa/verification.json` 和被 Git 忽略的本地截图。

测试范围包括搜索空态、不可用插座、当前任务入口、90 分钟结算支付、报修重复点击与刷新、订单筛选返回、320/390px 横向溢出、地图遮挡、无效链接恢复及页面运行错误。最新结果以 `qa/verification.json` 和实际命令输出为准。
