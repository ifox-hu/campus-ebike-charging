# 双插座设备与设备排

站点可配置多排设备，每台设备固定提供 A/B 两个独立插座。站点页按排展示设备，插座选择页采用两列布局。

## 数据迁移

旧版多插座设备按两个插座拆分，保留插座编号、订单与报修关联、占用及故障状态。新存储键为 `yun-mobile-demo-v2`，旧版 v1 数据作为迁移来源。

新建示例的插座编号采用设备号下的 `-01`、`-02`。历史插座保留原编号，包括旧版 `-03`、`-04`，保证已有订单仍可关联。联网设备由后端配置，页面按接口返回的设备和排号展示。

## 页面检查记录

2026-11-09 检查的首个示例站点包含3排：A排12台、B排15台、C排12台，共39台设备、78个插座。选择B排后显示15台设备、30个插座；设备选择页显示A/B两个插座。

当日39项测试通过，H5和微信小程序构建通过。浏览器检查覆盖启动、自动累计电量、结束结算和模拟支付。

## 计量与设备通信

本地演示按经过时间和功率计算电量，结束后按费率结算。联网模式由后端计量并保存订单。

TCP模拟器通过 `HELLO`、`HEARTBEAT`、`STATUS` 上报连接及设备状态，通过 `START`、`STOP` 接收控制指令。心跳用于在线检测，启动、停止与计量分别处理对应的反馈消息。
