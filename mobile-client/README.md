# 电动自行车智慧充电用户端

当前联机客户端，由原“云创用户端”目录复制纳入主仓库。原本地目录保留；此目录与 `frontend/` 管理端并列，`uni-app/` 为另一套保留的参考实现。

## 联机运行

需要Node.js 22。先按主仓库部署说明配置并启动配套 `ev-charging-platform/backend/`，默认API端口8081。

```bash
npm ci
npm run dev:connected
```

H5默认5198，通过本地 `/api` 代理访问8081。管理端 `frontend/` 的connected模式使用同一API，站点、订单及报修以服务端为准；Pages是独立静态演示。

## 构建和测试

```bash
npm test
npm run build:h5:connected
npm run build:mp-weixin
```

H5产物为 `dist/build/h5/`，线上需同源API反向代理。微信产物为 `dist/build/mp-weixin/`；在 `src/manifest.json` 设置自己的AppID，并按平台要求配置可访问的HTTPS API、合法域名。H5的开发代理不能用于真机，构建通过不代表真机或正式发布通过。

`npm run dev:h5` 是默认5197的独立本地演示，不与管理端静态页面共享订单。沙箱模式配置和支付宝接口说明见配套后端文档；环境模板只含开发地址，不含账号和密钥。

## 功能与边界

- 登录、场景筛选、站点搜索、设备与A/B插座选择、当前充电任务、订单与报修反馈。
- 定时1/2/3小时、自定义1—720分钟，充满自停为SOFTWARE预设曲线模拟，不检测真实电池SOC。
- 新订单只收电费，保存功率与费率快照；历史账单保留。微信/支付宝模拟渠道不扣款，外部支付宝沙箱需单独验证。
- 收藏和最近10站按API地址及账号隔离保存在本机；服务端刷新失败时显示旧数据及重试入口。
- 管理员分派报修、运营员处理本人工单，用户查看结果；结案不自动恢复设备故障。

完整验收与待测项见主仓库 `docs/graduation-acceptance.md`。此目录不包含原目录的Git元数据、node_modules、构建产物、本地配置、验收截图或第三方参考仓库。
