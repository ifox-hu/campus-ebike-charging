# 功能截图展示说明

## 来源与范围

- 管理端截图通过已发布的在线演示页面生成，页面、组件和操作均为实际运行结果；运营统计截图使用高德真实底图，并验证地图瓦片加载成功。
- 小程序用户端截图来自配套 uni-app 用户端的 H5 预览，与小程序共用页面代码；不是微信真机截图，也不表示已通过小程序发布审核。用户端源码位于仓库 `uni-app/`。
- 所有截图使用独立浏览器上下文和通用演示数据。管理端展示校园、住宅小区、园区三类示例站点，名称、地址和标记位置均为截图专用模拟数据，不代表真实充电设施；不使用本校楼栋与规划点位。地图道路、建筑和地名来自高德真实底图。应用默认数据、已登录用户、既有数据库均未修改。
- 充电及支付为软件模拟。充电中、定时结束及账单截图由模拟时钟构造演示场景，不对应实际电量或收款。

## 页面清单

以上截图记录生成时的三类场景演示，不是当前场景目录的完整清单。当前应用范围以校园为重点，覆盖住宅小区、医院、产业园区及企事业单位办公区，并含商业配套扩展示例；完整样本见[多场景演示站点](demo-scenarios.md)。新增站点和分类不会自动更新已有截图。

| 端 | 展示页面 | 图片文件 |
| --- | --- | --- |
| 管理端 | 登录、统计、设备排布、订单管理 | `screenshots/showcase-admin-*.png` |
| 用户端 | 找站、站点设备排布、开始充电、充电中、结束结算、订单、报修、个人中心 | `screenshots/mobile-*.png` |

## 可重复截图

在独立 QA 环境提供 Playwright 和 Microsoft Edge，先运行对应前端预览，然后执行：

```bash
node frontend/e2e/capture-admin-showcase.cjs
node frontend/e2e/capture-user-showcase.cjs
```

- `ADMIN_SHOWCASE_URL` 可指定管理端地址，默认使用已发布的在线演示；目标页面必须已配置高德地图，示意图模式不能通过截图检查。
- `MOBILE_SHOWCASE_URL` 可指定配套用户端本地演示地址。
- 脚本只修改隔离浏览器的演示夹具，不连接真实设备，不调用真实支付。

用户端验收包含：五种充电方式、时长对应金额、充电状态、定时结束、结算与模拟支付、订单记录和报修记录。
