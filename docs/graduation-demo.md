# 毕设答辩演示脚本

本脚本面向最终联机管理端、云创用户端和ev业务后端。演示前用独立演示库，不清空既有业务数据；先按部署说明核对版本与V11。不要把本地验收H2的3个站点当成正式业务目录，也不要把Pages样本数当成数据库站点数。

1. **交代范围**：校园为重点，医院、小区、园区等复用站点分类及相同业务流程。说明软件计量、模拟支付和沙箱边界；展示客户端与管理端访问同一后端。
2. **管理端运营概览**：展示今日启动单、已结算账单、电量、当前空闲插座、报修待办和异常设备。指出今日按订单开始日归属，结算金额不代表实收。点击异常设备或待办，再清除关联筛选；展示平铺菜单。
3. **用户找站**：场景筛选与名称搜索，进入站点，展示设备排和A/B插座。收藏后返回“收藏”及“最近浏览”。选择空配置站点时应显示未配置设备，不出现虚构价格或插座。
4. **启动并核对**：选择定时方案、插座及模拟支付方式，查看预计电费后确认。记录订单ID、站点与插座；管理端查询该订单，核对方案、计量来源、占用和电价快照。不要显示电池百分比。
5. **结束与结算**：用户提前结束，管理端和用户端核对同一账单与插座释放。短时间订单可能因两位小数为0，不篡改计量或账单制造金额；要展示收费可提前准备正常时长的已结束订单。已有非零账单可演示模拟支付，说明MOCK回执不扣款。重复请求应返回原结果。
6. **充满自停证据**：展示“软件模拟”提示和预设曲线说明，讲解后端215分钟模拟截止、低功率阶段及`FULL_SIMULATED`结束原因；用对应集成测试说明边界，不临时承诺几秒完成，也不冒充真实电池检测。
7. **报修处理闭环**：从设备/插座入口发起反馈，核对真实关联。管理员分派现有运营员，运营员处理本人任务并记录结果，用户刷新查看进度。另用权限测试说明其他运营员和其他用户不能越权。
8. **告警与异常**：对离线或故障告警填写核对说明，展示确认时间和账号，强调确认不会恢复故障或解锁插座。故障恢复后再次发生应有新的状态版本；展示重复请求、跨日、电价快照和补结算测试。
9. **收尾材料**：展示验收矩阵、最终架构、修订开题报告与任务书，说明已通过的测试、构建和浏览器检查；单独列出部署数据库升级、整进程重启、外部沙箱、开发者工具和真机待测项。

演示不要求新增功能或多级菜单。优先呈现“找到站—开始—查同一订单—结束释放—报修反馈”的完整逻辑，图表与页面用于帮助核对业务。
