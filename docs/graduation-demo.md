# 毕设答辩演示步骤

演示使用 `frontend/` 管理端、`mobile-client/` 用户端和配套业务后端。提前准备演示数据库，按 [部署说明](deployment.md) 配置 API 地址和数据库版本。

1. **介绍系统**：说明校园充电需求、用户和管理人员的操作流程，展示管理端与用户端。
2. **运营概览**：查看今日订单、结算金额、电量、空闲插座、待处理报修和异常设备，点击指标进入关联列表，再清除筛选。
3. **用户找站**：按场景筛选或名称搜索，进入站点，展示设备排和 A/B 插座；演示收藏、最近浏览及无设备站点的提示。
4. **启动充电**：选择插座和定时方案，查看预计电费并确认。记录订单编号，在管理端查找同一订单，核对方案、插座占用和费率快照。
5. **结束与结算**：提前结束订单，两端查看用电量、账单和插座状态。用已结束的非零账单演示模拟支付，再次提交时返回原结果。
6. **充满自停**：结合功率曲线说明正常负载、功率衰减和持续低功率三个阶段，展示 `FULL_SIMULATED` 结束原因及对应测试。300 W 示例在215分钟结束，累计约0.977 kWh。
7. **报修处理**：从设备或插座入口提交报修，管理员分派给运营员，运营员记录处理结果，用户刷新查看进度和时间线。
8. **告警与异常**：对离线或故障告警填写说明，查看确认人和时间；通过设备状态操作恢复故障，观察故障再次发生时的新提示。
9. **介绍实现与测试**：展示架构图、数据关系、核心接口和测试结果，说明并发占用、重复请求、权限、费率快照和自动结算的处理方法。

演示顺序为：找站选插座 → 启动充电 → 管理端查询 → 结束结算 → 报修处理。预先准备一笔正常时长的已结束订单，方便展示电量、账单和支付记录。
