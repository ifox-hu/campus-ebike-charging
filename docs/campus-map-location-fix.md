# 管理端校园地图坐标修正

日期：2026-11-09。目标是原管理端 5195 的真实高德地图，不是移动端 5203 的 CSS 示意图。

根因：原五处种子坐标经度约 112.52—112.53、纬度约 32.99，与南阳师范学院卧龙路校址不一致。仅修改站点名称、移动端种子或地图标题不能修正高德地图的实际落点。浏览器还会保留旧 v3 业务数据，修改种子不会自动更新已有缓存。

修正采用与底图一致的高德 GCJ-02 坐标。体育馆、东区网球场、西区校园参考以下高德 POI：

- 体育馆：`32.978854,112.489532`，https://www.amap.com/place/B017904HJ3
- 东区网球场：`32.977236,112.493175`，https://www.amap.com/place/B0HRVXFSZ1
- 西区校园：`32.975255,112.482660`，https://www.amap.com/place/B017900L0H

另两处中区点是按校园底图选择的演示规划位置：教学区 `32.9761,112.4893`、生活区 `32.9765,112.4877`。已在当前用户浏览器的高德底图目视核对校园范围。它们不是实际车棚测绘位置，不声称这些位置有真实充电设施。五个点统一为校园场景，并在界面显示南阳师范学院校园演示标题。

新增 `migrateCampusLocations`：仅匹配旧 ST01—ST05 的原名称与原坐标，将默认缓存升级到新校园坐标。手动修改过的坐标、名称与自建站保留。设备、插座、行排、费率、历史订单、报修不重建；不清除 localStorage，不操作后端数据库。兼容原 v2→v3 迁移后继续修正默认旧位置。

检查：单元测试覆盖校园位置、旧缓存位置迁移、业务数据保留与自建站保留；原站点地图搜索筛选、设备/报修跳转、断网示意和地图缩放拖动脚本继续验收。可视证据为 `qa/dashboard-campus-map.jpg`。构建中既有大包体提示保留，未为本次坐标修正改动打包结构。
