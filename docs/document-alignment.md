## 后续联调约束

starting / charging / abnormal 为占用中的订单；failed / ended 为终态。支付另存 unpaid / paid / none；界面分别表述为待支付、已模拟支付、无需支付。前端仍是模拟，不以本地互斥替代数据库事务。后续正式 API 必须由后端确定身份、插座占用、费率快照、电量与费用，前端只负责请求与展示。启动请求键只在当前本地模拟中提供重试识别，跨端重试须以后端幂等键为准。
