# 顶部功能完善

用户要求完善本地模拟标识、搜索、通知、全屏、字号和管理员账号入口。

## 本轮交付范围

- Spring Boot 管理员账号服务：登录、会话恢复、个人资料、原密码校验后改密、退出、密码变更使旧会话失效。
- 账号显示偏好持久化：标准/较大/大字号、表格密度；应用到整个后台。
- 通知：报修、设备离线、插座故障和异常订单；列表、未读筛选、单条/全部已读、跳转相关业务。已读状态按登录账号由服务端保存。
- 全局搜索：设备、站点、订单、报修与菜单入口，分组结果、空结果和键盘关闭。
- 全屏：实际状态、进入/退出、不支持提示。
- 状态标识：明确账号服务在线与充电业务仍为本地软件模拟，不再假装固定演示身份就是正式登录。

账号服务放在当前目录 server，使用 Java 17/Spring Boot，与旧程序相互独立。当前本机账号数据用文件数据库持久化；正式业务数据库和 H5/小程序联调不在本轮冒充完成。旧程序及用户端目录不改动。

初始本机管理员账号由服务启动时初始化；仅在没有账号时创建，绝不覆盖已修改的密码。密码用 BCrypt 保存，登录通过 HttpOnly 会话 Cookie 和 CSRF 保护；不把密码或令牌写入浏览器 localStorage。
