# 项目功能与代码质量优化

依据本轮已确认的优化建议实施，沿用现有页面、角色和数据结构。

## 交付内容

1. 管理端接入 ESLint、Prettier 和 CI 检查，展开压缩源码；提供可执行的开发规范。
2. 运营商和团队控制器只负责 HTTP；业务判断、事务与数据访问进入服务。统一重复返回类型，保留现有接口数据字段及角色隔离。
3. 报修处理从所属运营商的有效团队中选择处理人，保留已有分派；补充等待时长与超时筛选。平台跨运营商操作仍由后端检查。
4. 费率页面展示全天时段、缺口/重叠、服务费比例及计费预览；联网编辑提前校验与现有时段冲突。历史订单费率快照保持原样。
5. 管理端按快慢周期刷新：设备、插座和活动业务每五秒，基础资料及账号每六十秒或手动刷新；拆出刷新调度模块，保留退出失效、请求竞态保护。
6. 静态演示与联机页面同步可共用的流程改进，测试构建及线上部署验证后更新使用说明。

## 实施选择

沿用现有 Vue 页面和单体业务后端，按职责提取模块。暂不做数据库字段重命名、支付模式更换或全量技术栈迁移，以免改变历史记录和现有用户操作。

## 验收

原有测试通过；新增测试覆盖费率边界、跨运营商候选人、迟到请求、快慢刷新与分层后原事务行为。前端代码检查与构建通过；浏览器验证管理流程和演示部署。
