# 首页站点地图增量设计

用户已确认：在现有慧知风格首页的七张统计卡片之后、充电订单趋势之前增加站点地图，不重建首页。

保留侧栏、工具栏、今日/全部、全部指标及原有图表。新卡片左侧约70%为地图，右侧约30%为站点详情，桌面地图高度约430px，窄屏上下排列。复用旧demo高德JSAPI思路和本机已有配置，不增加依赖，不把旧首页整体迁入。

地图显示站点名称及空闲/总插座，支持名称地址搜索、状态筛选、选择站点与查看全部。右侧初始显示筛选范围概况，选中后显示该站点设备、空闲、充电中、故障、离线和待处理报修；按钮跳转原设备排布/报修页面并传递站点筛选。

只使用当前本地演示库及其既有状态规则，明确示例坐标和模拟数据。配置或网络不可用时显示标注清楚的坐标分布示意和错误/重试，不伪造真实底图。缺失或不合法坐标不落点，仍可选择站点查看详情。卸载与重试销毁地图，拒绝迟到初始化。

比较过独立地图页和重做首页；采用现有首页新增卡片，符合用户确认范围。联网版本的其他增强在另一工作树开发，本次不修改其文件，不迁移业务库、不改充电与结算逻辑。
