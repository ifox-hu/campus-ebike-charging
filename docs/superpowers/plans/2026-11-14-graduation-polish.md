# 系统页面与业务流程实施计划

计划日期：2026-11-14。设计见 [页面与业务流程设计](../specs/2026-11-14-graduation-polish.md)。

## 一、计费规则与运行配置

涉及管理端、`mobile-client/` 和配套业务后端。

- 核对两端启动命令、API地址、账号角色和数据库配置。
- 新订单仅计电费，保存功率与分时电价快照，保留历史账单。
- 调整新订单配置、预计电费及订单详情文案。
- 统一任务书与开题报告中的充电、计量和支付描述。
- 整理功能对应的页面、接口和测试记录。

## 二、管理端关联查询

涉及 `frontend/src/connected/`、`components/OperationsPanel.vue`、`domain/operations.js` 及对应测试。

- 统一订单日期、已结算金额和当前资源的统计方法。
- 概览展示业务指标、待办及现有趋势图表。
- 接通待处理报修、异常设备与站点关联查询，提供清除筛选入口。
- 订单详情显示定时或充满自停方案、计量来源、结束原因及历史缺失提示。
- 检查空列表、无权限资源和已变化记录的反馈。

## 三、用户端交互

涉及首页、站点、启动、充电中、订单和报修页面，以及 `src/api/customer-store.mjs`。

- 完善当前任务入口和站点信息层级。
- 保留场景筛选、收藏和最近浏览，按账号保存本机记录。
- 统一预计电费、功率变化、计量来源和结束原因。
- 从设备或插座进入报修时带入资源ID。
- 检查无设备、无费率、网络失败、登录过期、重复点击和退出后的数据清理。
- 检查H5窄屏布局和微信导航栏、键盘及返回操作。

## 四、业务测试

- 用户启动 → 管理端查单与占用 → 结束结算 → 释放插座 → 两端核对。
- 用户报修 → 管理员分派 → 运营员处理 → 用户查看进度。
- 并发占用、重复结束与支付、越权、跨日和费率快照。
- 充满自停的有效负载、持续低功率、采样间断、断线和重启。
- 定时补结算、停止失败保留占用及重试。
- 分别构建管理端connected/Pages、用户端H5与微信小程序。

测试使用隔离数据库和测试账号。操作步骤与结果记录在 [联机测试记录](../../graduation-acceptance.md)。

## 五、文档与演示

- 按学校模板整理任务书和开题报告，保留个人信息、签字区和进度安排。
- 统一充满自停、电费和支付描述。
- 更新系统架构、数据关系、订单状态和报修流程图。
- 按找站、启动、管理端核对、结束结算和报修处理组织演示。
- 检查Word分页、表格、字体和参考文献格式。

实施顺序为：计费规则与运行配置 → 页面交互 → 业务测试 → 文档与演示。
