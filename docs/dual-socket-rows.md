# 双插座设备及多排摆放修正

依据：用户当前补充，以及用户提供的模块架构修订版开题报告与任务书。

此前把数量可配置主要做成了单台设备 1～64 插座，且用七插座设备演示，偏离实际描述。本轮改正为：站点/集中停车点 → 多个设备排 → 一排多台双插座设备 → 每台 A、B 两个独立插座。排只是站点内的物理分组，不新增运营角色。

- 每站可添加多排；每排典型十几台设备，数量可追加，不固定 20。
- 当前设备规格固定双插座，新增和编辑不再提供七路、十路等选项。
- 设备页面默认按实际排分组，横向按设备序号展示；列表视图仍可筛选维护。
- 设备在线/停用以及 A、B 插座的空闲、充电、故障与异常占用分别展示。
- 已有 v2 本地演示数据保留原键；向新 v3 键迁移，按双插座拆分旧多口设备，并保留插座 ID、订单及报修关联。奇数插座补齐空闲 B 口。旧示例站补充典型设备排，用户新增站点不擅自填充。
- 两份 Word 文件本轮只读取核对，不修改正文。

验收：多个排、每排十几台、每台恰好两个插座；增加一台设备，插座总数增加 2；历史订单、当前占用、报修不丢失；构建及规则测试通过。
