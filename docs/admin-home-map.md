# 管理端首页站点地图

更新：2026-11-09。修改原目录 `慧知界面复刻` 的5195本地演示首页，不是新建首页。

## 放置与交互

地图卡片位于七张统计卡片之后、充电订单趋势之前。保留今日/全部切换、报修告警、用户增长、费用统计、设备表和占比图。左侧是真实高德底图，右侧是全部站点概况或选中站点详情。

- 支持名称、地址、编号搜索及全部/有空闲/有异常/已停用筛选。
- 点击地图标记或右侧站点选择框，联动设备、插座、空闲、充电中、故障、异常占用、离线及待处理报修统计。
- 查看设备排布和查看报修直接进入原页面，自动带上站点筛选。
- 原有坐标为GCJ02示例位置；不代表站点实际部署。坐标缺失或非确认GCJ02数据不落点，但仍可查询详情。
- 未配置地图或服务断网时，明确显示非真实底图的坐标分布示意；详情、搜索和跳转仍可用。

## 配置

优先使用本目录未跟踪的 `.env.local` 中 `VITE_AMAP_KEY` 与 `VITE_AMAP_SECURITY_CODE`，样例见 `.env.example`。未配置时复用相邻原demo `ev-charging-platform/frontend` 的同名本地前端配置；不复制或提交凭证。配置改变后重启Vite。

所有状态来自本地演示库，与当前5195首页既有数据口径一致；不修改账号、真实设备或后端数据库。另一工作树中的联网统计等功能不在本次改动范围内。
