目标：以用户指定文章中的原始截图为视觉依据，重新实现可运行、可交互的前端，不继续使用此前自绘方案。

来源：https://cloud.tencent.com/developer/article/2691703

实现：独立 Vue 3 + Vite 前端，沿用截图中的左侧导航、顶部工具栏、紫蓝渐变、白色统计卡片、图表布局与列表样式。图表用 ECharts 绘制，不能用整张截图充当界面。已有程序与上游源码预览不覆盖。

本轮范围：优先完整复刻用户指定的统计首页；文章中能明确辨识的设备列表、订单等页面按截图实现。按钮、选项卡、导航、筛选、导出和弹窗提供本地演示交互。示例数据明确标注，正式后端后续接入。未公开的商业源码不声称已经取得；不可见页面不声称已逐像素复刻。

验收：本地启动，构建通过；桌面尺寸对照原图检查整体比例、字体、留白、颜色、卡片和图表；验证导航及主要交互。复刻视觉接近程度据实际截图描述，不承诺无法验证的百分之百一致。
